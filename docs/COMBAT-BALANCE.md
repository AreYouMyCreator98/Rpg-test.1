# Progression and combat balance — realm-balance-1

- Level thresholds doubled (level 1: 45 → 90 XP). Reward numbers stay the same, so quests, combat and bounties all progress levels more slowly. Existing levels, absolute XP, attributes and unlocks remain; nobody loses a level.
- Skill budget is three points per level gained, including past levels: `(level − 1) × 3 − unlocked nodes`. Repeated loading cannot duplicate the award. Nodes still cost one point; the existing 18-node tree can therefore be completed by level 7. Unspent points remain available.
- Enemy home region adds 22% base HP and 10% base damage per difficulty tier, rounded before the existing post-level-20 scaling. Graveyard 0; village outskirts 1; river/wider roads 2; northern camps 3; western hostile territory and marsh approaches 4; far north 5. Hollowroot 2, Rootbound 3, Sunken 4, Frostspire 5, Forge 6. Moving the player or dragging an enemy across a boundary never changes its region. XP rewards do not increase with these multipliers.
- A successful stagger lasts 0.16 seconds for a light hit or the existing heavy-hit duration. It is followed by 1.6 seconds of stagger resistance (2.8 for bosses). Protected hits still deal damage but cannot reset attack cooldown or reapply knockback. All attacks gain interruption protection after 22% of their wind-up; bosses, including Gruk, resist light-hit stagger entirely. Heavy hits can still interrupt an uncommitted boss outside its recovery window.

Trusted server thresholds, skill spending/import budgets and catalogue stats are updated too. Existing in-progress account encounters retain their persisted HP until respawn; no live encounter history or character record is deleted. Apply `combat-balance.sql` and `game-catalog-seed.sql` for existing installations. The migration patches only relevant function expressions, preserving installed regional-trade/security changes, and is idempotent. Updated baseline SQL supports clean installs.

Validated: progression unit tests; PGlite reward/ownership/XP/point-budget regressions; actual Chromium game tests for old level-20 saves, level-up awards, all 114 catalogue stat matches, stronger regional tiers, boss commitment protection and enemy retaliation while receiving ten light hits per second. Physical-device and subjective long-term difficulty testing remain unverified.
