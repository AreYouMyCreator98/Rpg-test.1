# Contextual world gathering

Release `realm-gathering-2` extends the existing workshop system to the actual forest roots and rock deposits. `world-resources.js` freezes 9,659 coordinates from the rendered world; IDs are append-only. The browser test checks that this catalog agrees with the scenery. Small decorative plants, pebbles and props are not resource deposits.

Approach a tree or rock within 3.3 units with its axe/pickaxe owned in an editable base pack. The existing interaction button automatically becomes **Gather wood** or **Gather stone**, with a matching tool icon; desktop E uses the same action. No tool selection or menu visit is necessary. Existing marked wood, stone and ore nodes continue to work, including their loose-material bootstrap. Selected base is preferred, with the other editable base used if it owns the required tool. Materials enter that base's builder pack, retaining storage, recipes and quest credit.

Each tap performs the existing tool stroke. Stone tools take three hits and iron tools two. Depletion awards six logs/rough stone or four ore at marked ore deposits. Forest scenery remains standing while its harvestable supply regenerates. Depleted resources display their remaining wait. All newly depleted resources recover after **72 elapsed minutes**, equivalent to three 24-minute game days. This is a real elapsed-time cooldown, including offline time; pausing the world clock does not pause regrowth. Existing saves retain any cooldown already in progress.

`supabase/world-gathering.sql` is applied **after** `homesteads.sql` (including on fresh installations). It installs the private authoritative catalog and updates `realm_workshop_apply`. The live project has received this migration. Clients cannot insert or edit resource coordinates. The existing authenticated estate RPC still validates ownership, location, tool rank, per-stroke cooldown, stock limits, version and request replay. Cloud cooldowns use server time; guest/offline saves necessarily use the browser clock. Expired forest-node state is pruned on gathering to avoid unbounded save growth.

Validation performed: gathering rules tests (including exact regeneration boundary and save cleaning), PGlite authenticated SQL tests (ordinary nodes, forged location, unknown IDs, cooldown, owner isolation and private catalog), actual Chromium mobile game tests (tool crafting, automatic prompts, wood/stone animations and rewards, depletion and reload). Physical-phone and live two-client testing were not performed for this change.
